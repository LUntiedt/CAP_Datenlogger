# Messungen

- `protocols/` – Messprotokolle (Markdown), Vorlage `protocols/0000-vorlage.md`
- `data/` – Messdaten; Dateiname `JJJJ-MM-TT_<messung>_<geraet>.<ext>`
  - `data/referenz/` – Referenzaufnahmen aus dem Vorgängerprojekt

Große Rohdaten: Wenn die GitLab-Instanz Git LFS anbietet, über LFS (siehe `.gitattributes`),
sonst nur Ausschnitte committen und den Ablageort der vollständigen Daten im Protokoll nennen.
