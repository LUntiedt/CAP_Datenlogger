## Aufbau jeder AP-Datei

1. **Kopf:** Verantwortlich, Zeitraum, Bezug zu Anforderungen
2. **Ziel:** was am Ende vorliegt
3. **Aufgaben:** nach Meilensteinen gegliedert, als Checkboxen
4. **Schnittstellen:** was man von anderen braucht und an wen man liefert
5. **Ergebnisse:** Links auf Dateien im Repo
6. **Stand / Offene Fragen / Log:** wird laufend gepflegt

Aufgaben dürfen präzisiert, ergänzt oder gestrichen werden – mit kurzer Notiz im Log.
