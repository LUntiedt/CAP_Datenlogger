# ap-start

Wir beginnen eine Arbeitssitzung an **<ARG>** (z. B. AP2). Noch keinen Code und keine Schaltung ändern.

1. Lies `STATUS.md` und `docs/ap/` die Datei zu <ARG>.
2. Lies die Abschnitte des Pflichtenhefts (`docs/spec/pflichtenheft.md`) und die Anforderungen
   im Lastenheft, die im Kopf der AP-Datei unter „Bezug“ stehen.
3. Lies die ADRs in `docs/decisions/`, die dieses AP betreffen.
4. Fasse auf Deutsch zusammen (kurz):
   - wo das AP gerade steht,
   - welche offenen Aufgaben bis zum nächsten Meilenstein anstehen,
   - was von anderen APs gebraucht wird und noch fehlt,
   - welche offenen Fragen es gibt.
5. Schlage die nächsten 1–3 Schritte für diese Sitzung vor und frage, womit wir anfangen.

Halte dich an `AGENTS.md`, insbesondere: keine geratenen Datenblattwerte, Entscheidungen als ADR.
