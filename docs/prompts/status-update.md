# status-update

Erstelle einen Vorschlag für die neue `STATUS.md`.

1. Lies die aktuelle `STATUS.md`, `docs/PLAN.md` und alle Dateien in `docs/ap/`.
2. Lies `git log --since="2 weeks ago" --oneline` für die letzten Änderungen.
3. Aktualisiere: Datum, Projektwoche, aktuelle Phase, Status der Meilensteine,
   Stand je AP (ein Satz), Blocker, nächste Schritte.
4. Markiere Meilensteine als 🔴 gefährdet, wenn offene Aufgaben dafür sprechen, und begründe das.
5. Behalte Format und Umfang (eine Seite) bei. Zeige den Diff und frage vor dem Speichern.
