# session-end

Wir beenden die Arbeitssitzung. Bevor committet wird:

1. Fasse zusammen, was in dieser Sitzung geändert wurde (`git status`, `git diff`).
2. Aktualisiere die betroffene AP-Datei in `docs/ap/`: Checkboxen, Abschnitt „Stand“
   (ein bis drei Sätze), „Offene Fragen“, Log-Eintrag mit Datum.
3. Wurde etwas entschieden? Dann `docs/prompts/decision.md` ausführen.
4. Schlage eine Commit-Nachricht nach `AGENTS.md` Abschnitt 9 vor
   (`typ(bereich): Beschreibung auf Deutsch`).
5. Weise auf Dateien hin, die nicht committet werden sollten (Build, Backups, persönliche Einstellungen).
