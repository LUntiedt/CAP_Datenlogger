# Datenblätter

PDFs der gewählten und ernsthaft verglichenen Bauteile hier ablegen, Dateiname
`<bauteil>_<revision>.pdf` (z. B. `lsm6dsv16x_rev7.pdf`). Nur Bauteile, die wirklich
gebraucht werden; die Kandidatenübersicht steht in `docs/components.md`.

Für die Firmware relevante Register werden nach `docs/registers/` übertragen.
