# Budgets

`budget.py` rechnet Energie- und Speicherbudget und reproduziert Tabelle 1 und 2 des
Pflichtenhefts. Zahlen werden hier gepflegt und von anderen Dokumenten verlinkt,
nicht abgeschrieben.

```bash
python3 docs/budgets/budget.py
```

- **AP1** ergänzt den Strom je Betriebszustand (Abschnitt `STATES`) und die Laufzeitrechnung.
- **AP3** ergänzt nutzbare Kapazitäten der Speicherkandidaten und Overhead für Header/Zeitstempel.
